# Local Market – Online Store for Small Vendors

## About the Project
Local Market is a simple e-commerce website where local vendors can display their products online and customers can shop from different local stores.

## Project Objective
The main objective of this project is to help small local businesses reach more customers through an online platform. It also makes shopping easier by allowing customers to explore products, place orders, and track their purchases.

## Features

### Implemented Features
- Browse, search, filter, and sort products.
- Shopping cart and wishlist.
- Customer registration and login.
- Vendor registration and store management.
- Add, edit, and delete products.
- Inventory and stock management.
- Place orders and track order status.
- Apply discount coupons.
- Product reviews and ratings.
- Notifications for order updates.
- Admin dashboard for managing vendors, products, and orders.

### Planned Improvements
- Real online payment integration.
- Secure authentication.
- Shared database for multiple users.
- Email and SMS notifications.

## Technologies Used
- **HTML** – Website structure
- **CSS** – Styling and responsive design
- **JavaScript** – Website functionality
- **localStorage** – Saving data in the browser

## How to Run
1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html` and select **Open with Live Server**.

## Limitations
This is a frontend-based college project. Data is stored in the browser, and digital payments are simulated. Real payments and secure multi-user access require a backend.
